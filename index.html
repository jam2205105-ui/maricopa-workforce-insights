Median wage

Employment estimate

Estimated local workers in an occupation, not job openings or job postings.

Geography matters

Phoenix–Mesa–Chandler MSA includes both Maricopa and Pinal counties. The unemployment rate shown is specifically for Maricopa County.

How fresh is “live”?

The scheduled pipeline checks labor-market data daily and refreshes the O*NET directory from its published database. Official reporting periods differ: OEWS wages are annual, BLS monthly indicators are monthly, and O*NET database versions are periodic.

Pipeline, methodology and known limitations

Automated source ingestion downloads the complete O*NET occupation directory, monthly BLS LAU/CES time series, annual BLS OEWS metropolitan occupation wages, and optional Census ACS data when an API key is configured. Each feed is validated before publishing. A failed refresh preserves previous successfully published observations with a warning, never fabricated replacements.

For program planning, the candidate career-to-program associations need faculty approval and official CIP/SOC crosswalks. Unmapped occupations link to the official MCCCD catalog rather than making an unsupported program assertion. This version does not contain actual MCCCD enrollments, persistence, completions, or confidential student data. Job postings do not equal openings, and OEWS cannot be interpreted as employment projections. The official hosted O*NET widget cannot send scores directly to this cross-origin website. Students manually import their six scores, which are compared on-device with O*NET public occupational interest profiles using Pearson correlation. These are exploratory pattern similarities, not official O*NET Web Services match labels.
